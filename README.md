# PastelClient
Доминируй на сервере без лишнего риска.

Современный клиент для Minecraft, созданный с упором на стабильный PvP-геймплей и удобство в выживании. Главная особенность — тщательно настроенная KillAura с продвинутой системой ротаций и рандомизацией, которая уверенно проходит проверки популярных античитов (Grim, Matrix, Vulcan и др.).

Ключевые возможности:

Продвинутый Combat: Умная KillAura с настройкой фова, дистанции, задержек и плавным наведением (Silent/Smooth rotations), Velocity, AutoTotem и CrystalAura.

Полезный PvE и Utility: Авто-фарм мобов и ресурсов, Baritone-интеграция, X-Ray, ChestStealer, Scaffold с легитной постановкой блоков и удобный HUD.

Гибкая кастомизация: Интуитивно понятное ClickGUI с системой конфигов — делитесь настройками под конкретные серверы в один клик.
